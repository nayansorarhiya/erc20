# ERC-20 Token Interface

## Overview
This project is an interface for interacting with ERC-20 tokens on the Binance Smart Chain (BSC) testnet. It allows users to connect their wallet, add contract addresses, and perform operations based on available function calls regarding that contract. The frontend is built using React and integrates with the testnet blockchain using Ethers.js.

## Features
- Connect Ethereum wallet using Ethers.js
- Add ERC-20 token contract address
- Display token details (name, symbol, total supply, etc.)
- Perform operations like transferring tokens, checking balances, and approving allowances
- Interactive UI built with React

## Technologies Used
- **Solidity**: For writing the ERC-20 token contract
- **React**: For building the user interface
- **Ethers.js**: For blockchain interactions
- **Remix**: For contract deployment and testing

## Getting Started
### Prerequisites
- Node.js and npm installed
- MetaMask extension installed in your browser
- An BSC wallet with some test BSC (faucet: https://www.bnbchain.org/en/testnet-faucet)
